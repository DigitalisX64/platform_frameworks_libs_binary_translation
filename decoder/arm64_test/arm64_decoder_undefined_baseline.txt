# Mnemonics in arm64_decoder_encodings.txt that the ARM64 decoder reports as
# Undefined.
#
# Most are ISA extensions outside the implemented baseline (A64 base plus
# AdvSIMD/NEON and crypto) -- SVE/SVE2, SME/SME2, FP8, FEAT_FHM,
# FEAT_FAMINMAX, FEAT_THE -- where Undefined is the correct decode. They reach
# the corpus because it is harvested from current libraries, which contain
# runtime-dispatched code paths for CPUs that have those features.
#
# Three groups here are NOT extensions but genuine gaps in implemented
# territory, verified by hand:
#   * fmaxv / fminv / fmaxnmv --- the FP16 (half-precision) across-lane forms.
#     The .4S forms decode and execute; the Q=0, sz=0 half-precision forms
#     (e.g. 0x0e30f800) do not.
#   * sqdmull / sqdmlal / sqdmlsl --- the SCALAR forms (top byte 0x5e/0x5f,
#     e.g. 0x5e77d12e). The vector three-different forms decode.
#   * mrs / msr --- specific system registers, not the instructions as a whole;
#     MSR-immediate to a PSTATE field is covered by MsrImmediatePstateIsNop.
#
# A mnemonic that decodes to Undefined and is NOT listed here fails
# DecoderObjdumpDiff.UndefinedCoverageBaseline: something that used to decode no
# longer does. A listed mnemonic that starts decoding is reported, not failed --
# delete its line in the commit that implements it.
#
